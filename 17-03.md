- JavaScript es un lenguaje de programacion que permite agregar interactividad a las paginas web.

Con JS podemos..

    - Modificar el contenido

¿Por que se separa el codigo?

seprar en distintos archivos tiene varias ventajas: 
- Orden: Cada archivo tiene una funcion 
- Reutilizacion: El mismo CSS puede usarse en muchas paginas 
- Mantenimiento: Mantiene bien las paginas web

- Que es una calse (class)

    Una clase permite aplicar estilos a varios elementos.

    ejemplo: 
        <P class="texto">Primer parrafo</p>
        <p class="texto">Segundo parrafo</p>

    ambos tienen clases texto. En CSS se usa asi...

    .texto
        {
            color: green;
        }

    # El punto "." indica la clase
