## ¿Que rol cumple HTML, CSS y JS?

CSS controla cosas como 
- Colores
- Tamaños 
- Posicion
- Margenes
- tipografias

# ejemplo CSSS
hl
    {
    color: blue;
    font-size: 40px;

- JavaScript es un lenguaje de programacion que permite agregar interactividad a las paginas web.

Con JS podemos..
    - Reaccionas a clics 
    - Validar formularios
    - Modificar el contenido 
    - Utilizar API´S

¿Por que se separa el codigo?

seprar en distintos archivos tiene varias ventajas: 
- Orden: Cada archivo tiene una funcion 
- Reutilizacion: El mismo CSS puede usarse en muchas paginas 
- Mantenimiento: Mantiene bien las paginas web

- Que es una calse (class)

    Una clase permite aplicar estilos a varios elementos.

    ejemplo: 
        <P class="texto">Primer parrafo</p>
        <p class="texto">Segundo parrafo</p>

    ambos tienen clases texto. En CSS se usa asi...

    .texto
        {
            color: green;
        }

    # El punto "." indica la clase

    Ejemplo practico con "div" y span" 

    # HTML: 
    <div class="tarjeta">
    <h2>Curso aprendiendo <span class="destacado">HTML y CSS</span>.</p>
    </div>

    # CSS: 
    .tajeta {
        background-color: lightblue;
        padding: 20px; }
    .destacado {
        color: darkred;
        font-wieght: bold; }

Ejercicio 2:
<!DOCTYPE html>
<html>
<head>
    <title>Ejercicio 2</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <div class="caja-principal">
        <h1 id="titulo-destacado">Modelo de Caja</h1>
        <p class="texto-importante">Aquí estoy aplicando clases, ID y Box Model.</p>
    </div>
</body>
</html>

CSS: 
/* Uso de ID (debe ser único) */
#titulo-destacado {
    color: darkblue;
    text-align: center;
}

/* Uso de Clase (se puede repetir) */
.texto-importante {
    color: darkgreen;
    font-size: 20px;
}

/* Aplicación del Box Model al contenedor div */
.caja-principal {
    background-color: lightblue;
    width: 300px;
    padding: 20px;
    border: 2px solid blue;
    margin: 30px;
    border-radius: 10px;
}

CSS:
/* Box Model general */
.contenedor {
    background-color: #f0f0f0;
    padding: 20px;
    border: 2px solid gray;
    margin: 30px;
}

/* Identificadores y Clases */
#inicio { color: darkblue; }
#contacto { color: darkgreen; }
.descripcion { font-size: 18px; }

/* Uso de Span para partes pequeñas del texto */
.destacado { 
    color: red; 
    font-weight: bold; 
}

/* Estilo de enlaces y estado Hover */
a {
    color: blue;
    text-decoration: none; /* Quita el subrayado */
}

a:hover {
    color: red; /* Cambia a rojo al pasar el mouse */
}
